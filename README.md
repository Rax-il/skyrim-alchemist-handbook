# Справочник алхимика Skyrim

<p align="center">
  <img src="docs/images/cover.jpg" alt="Alchemist's Handbook for Skyrim" width="480">
</p>

Настольное приложение-помощник для алхимии в **The Elder Scrolls V: Skyrim**.
Решает две обратные задачи, с которыми сталкивается любой игрок за
котелком: *"мне нужен эффект X (или сразу несколько) — из каких
ингредиентов его сварить?"* и *"вот что у меня есть в инвентаре — какие
зелья/яды из этого вообще получаются?"*. Ищет сочетания из 2–3
компонентов по совпадающим свойствам, показывает состав и описание
каждого ингредиента, и позволяет редактировать базу под себя (свои
находки, модифицированные ингредиенты и т.д.).

База данных приложения покрывает ингредиенты базовой игры, всех
официальных дополнений (Dawnguard, Dragonborn, Hearthfire), надстроек
Saints & Seducers и Plague of the Dead, а также ингредиенты из
популярного мода **Rare Curios**. Интерфейс переведён на 9 языков
(русский, английский, немецкий, испанский, французский, итальянский,
польский, японский, китайский).

Приложение написано на **Tauri 2 + Rust + React + TypeScript + Vite +
Mantine**: вся логика поиска и хранения — на стороне Rust
(`src-tauri/src/db.rs`, чистые функции над SQLite-базой), интерфейс —
веб-страница на React внутри системного WebView (WebView2 на Windows).
Портативно: не требует установки, не пишет в реестр, база и настройки
хранятся рядом с исполняемым файлом.

**Системные требования:** Windows 10/11 или Linux (`.deb`). На Windows
нужен установленный **WebView2 Runtime** — он идёт предустановленным на
актуальных сборках Windows 10/11; если его нет, приложение подскажет
скачать его с [сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

## Технологии и структура проекта

- **Frontend:** React 19 + TypeScript + Vite + [Mantine](https://mantine.dev/) UI-kit, `i18next`/`react-i18next` для переводов.
- **Backend:** Rust + [Tauri 2](https://tauri.app/) (десктоп-обвязка вокруг системного WebView), [`rusqlite`](https://docs.rs/rusqlite) с бандленным SQLite-движком (не требует системной библиотеки SQLite на машине пользователя).
- **Хранение данных:** одна SQLite-база (`alchemist.db`), поставляется вместе с приложением уже заполненной.

```
src/                          — фронтенд (React + TS + Mantine)
  App.tsx, main.tsx            — сборка интерфейса, состояние приложения
  components/                  — ControlPanel, TopPane, BottomPane,
                                  EditorModal, SettingsModal, AboutModal,
                                  ThanksModal, HintIcon
  lib/api.ts                   — типизированная обёртка над invoke()
  lib/addons.ts, languages.ts,
  lib/appTheme.ts               — справочники для настроек (источники
                                  данных, языки, темы/масштаб)
  i18n/                         — react-i18next, locales/<lang>/translation.json
                                  для 9 языков

src-tauri/                    — бэкенд (Rust)
  src/db.rs                    — схема БД, поиск сочетаний, CRUD
  src/seed_data.rs,
  src/rare_curios.rs,
  src/creations.rs             — исходные данные (ингредиенты/свойства)
  src/addons.rs                — источники ингредиентов (DLC/моды) и их
                                  включение/выключение
  src/layout.rs                — сохраняемая раскладка окна/панелей
  src/commands.rs               — #[tauri::command]-обёртки над db.rs для React
  src/lib.rs, main.rs           — инициализация приложения
  src/paths.rs                  — alchemist.db и alchemist_settings.json
                                  кладутся рядом с exe (портативность)
  alchemist.db                   — готовая база с картинками и описаниями
```

## Возможности

1. **Поиск сочетаний по свойствам.** Выбираете до 4 нужных эффектов и
   фильтр "Все / Улучшения / Яды" — приложение находит все сочетания
   из 2–3 ингредиентов, дающих эти эффекты, со списком компонентов
   каждого варианта.
2. **Парные сочетания.** Отдельная кнопка: находит пары ингредиентов,
   дающие максимальное количество совпадающих эффектов — без ручного
   выбора конкретных свойств.
3. **Тройные сочетания.** То же самое, но для троек ингредиентов.
4. **Просмотр свойств ингредиента.** Выбираете компонент из списка —
   видите все его эффекты, картинку и описание.
5. **Редактор базы.** Добавление, переименование и удаление
   ингредиентов; редактирование их 4 свойств, картинки и описания —
   можно вносить свои находки или правки под изменённые модами
   ингредиенты.
6. **Фильтр по источникам.** В настройках можно включать/выключать
   базовую игру, каждое официальное дополнение, Rare Curios и
   собственные добавленные ингредиенты по отдельности — результаты
   поиска учитывают только включённые источники.
7. **Многоязычный интерфейс.** Полный перевод на 9 языков (русский,
   английский, немецкий, испанский, французский, итальянский,
   польский, японский, китайский) — переключается в настройках без
   перезапуска.
8. **Настройки интерфейса.** Масштаб (мелкий/нормальный/крупный),
   цветовая тема (светлая/тёмная/системная/фирменная "Skyrim"),
   ограничение числа отображаемых сочетаний.
9. **Портативность.** Не требует установки (кроме Linux-пакета .deb),
   не пишет в реестр — база данных и настройки хранятся рядом с
   исполняемым файлом. Раскладка окна (размер, позиция, ширина панелей)
   запоминается между запусками.

## Что стоит перепроверить при первом запуске

Я не смог собрать и запустить Tauri-приложение в этой песочнице — здесь
нет ни Rust, ни системных библиотек для WebView (только Node/npm). Поэтому:

- **Фронтенд** — я прогнал `tsc -b` и `npm run build`, компилируется и
  собирается без ошибок. Логику UI (стейт-машина топ/боттом-панелей,
  редактор) я тщательно сверил построчно с исходным `main.rs`/`editor.rs`,
  но живого клика мышкой по факту не было.
- **Rust-часть** — код я не компилировал (нет `cargo` в этой среде).
  Сигнатуры API `tauri-plugin-dialog` и `tauri-plugin-window-state`
  я перепроверил по актуальной документации v2, но при первой сборке
  возможны мелкие несостыковки версий (обычно чинится в одну строку —
  Rust-компилятор для таких вещей даёт очень точные сообщения об ошибке).
- Ручки перетаскивания (ширина панели, разделитель верх/низ) реализованы
  вручную через mousedown/mousemove — работать должны, но UX стоит
  сравнить с тем, что было в egui, и подправить чувствительность при
  необходимости.

Если что-то не соберётся с первого раза — пришлите мне текст ошибки
`cargo build`/`npm run tauri build`, разберём.

## Сборка из исходников

### Шаг 1. Установить инструменты (один раз)

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# Node.js 18+ и npm — если ещё не стоят
```

Системные зависимости для запуска/сборки Tauri **на Linux** (нужны только
для `npm run tauri dev` — посмотреть приложение живьём на Linux; для сборки
самого Windows-exe не нужны):
```bash
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
```

### Шаг 2. Установить зависимости проекта

```bash
npm install
```

### Шаг 3. Разработка (живой просмотр на Linux)

```bash
npm run tauri dev
```
Откроется окно с приложением, hot-reload фронтенда работает как обычно
в Vite.

### Шаг 4. Собрать .exe под Windows — два варианта

> **Про предупреждение Windows при первом запуске.** Оба варианта дают
> обычный, не подписанный цифровой подписью `.exe` — при первом запуске
> Windows SmartScreen (или антивирус) почти наверняка покажет
> предупреждение вида "Windows защитила ваш компьютер" / неизвестный
> издатель. Это нормально для небольших независимых приложений без
> платного сертификата подписи кода — нужно нажать "Подробнее" →
> "Выполнить в любом случае".

#### Вариант А (рекомендуется): собрать прямо на Windows

Как и раньше с egui-версией, самый надёжный способ — поставить Rust и
Node на саму Windows-машину (или в CI на Windows-раннере) и собрать
штатно:
```powershell
rustup default stable-msvc
npm install
npm run tauri build
```
Готовый файл — `src-tauri/target/release/alchemist.exe`. Так как
`bundle.active` выключен в `tauri.conf.json` (см. ниже, почему), инсталлятор
не создаётся — просто портативный exe, ведёт себя один в один как раньше:
кладёте `alchemist.exe` и `alchemist.db` в одну папку — работает.

#### Вариант Б: кросс-сборка с Linux

Здесь всё сложнее, чем было с чистым Rust-бинарником через
`x86_64-pc-windows-gnu` — Tauri тянет за собой WebView-обвязку (`wry`/`tao`),
которая под Windows завязана на MSVC, а не на mingw-gnu. Рабочий путь —
через **`cargo-xwin`** (эмулирует MSVC-линковщик и подтягивает нужные
заголовки/библиотеки Windows SDK автоматически, ничего скачивать вручную
не нужно):

```bash
rustup target add x86_64-pc-windows-msvc
cargo install cargo-xwin
cargo install tauri-cli --version "^2"

npm install
npm run build                 # сначала собрать фронтенд (dist/)
cd src-tauri
cargo xwin build --release --target x86_64-pc-windows-msvc
```
Готовый файл — `src-tauri/target/x86_64-pc-windows-msvc/release/alchemist.exe`.

Если `cargo xwin` даст сбой (случается на некоторых версиях зависимостей
webview-стека — это известное больное место кросс-сборки Tauri, менее
стабильное, чем было у чистого egui/eframe) — не тратьте на это много
времени, переходите на вариант А (сборка прямо на Windows) или на GitHub
Actions с `windows-latest` раннером, где `npm run tauri build` работает
из коробки.

### Про базу данных

Как и раньше: `alchemist.db` (уже с 178 компонентами, 61 свойством и всеми
картинками) лежит в `src-tauri/`. После сборки скопируйте её рядом с
получившимся `alchemist.exe` — программа найдёт её по пути рядом с exe
(`paths.rs`, чуть надёжнее, чем прежний "рабочая директория процесса" —
теперь работает независимо от того, как именно запущен exe).
