# Подсказки-«вопросики» — дизайн

Дата: 2026-08-11

## Контекст

В интерфейсе есть несколько мест, где поведение неочевидно без пояснения:
формулировка «(Только для текущего языка)» у Описания в редакторе базы (сама
формулировка появилась в плане B3+B4), лимит «Макс. кол-во сочетаний» в
Настройках, и разница между кнопками «Парные сочетания»/«Тройные сочетания»
и обычным поиском по свойствам. Раньше в проекте не было интерактивных
пояснений — только статичный текст.

## Что добавляется

Один переиспользуемый компонент — маленький значок «?» в кружке (в коде —
`HintIcon`, в разговоре — «вопросик»), при наведении на который всплывает
подсказка с текстом. Используется в четырёх местах:

1. **`EditorModal.tsx`** — рядом с «(Только для текущего языка)» у поля
   «Описание»: «Корректировки описания ингредиента будут сохранены только
   для текущего языка»
2. **`SettingsModal.tsx`** — рядом с меткой «Макс. кол-во сочетаний»:
   «Количество комбинаций ингредиентов, отображаемое при нажатии на кнопки
   «Парные сочетания» и «Тройные сочетания»»
3. **`ControlPanel.tsx`**, кнопка «Парные сочетания» — прямо на кнопке:
   «Вывести сочетания двух ингредиентов, дающих максимальное количество
   эффектов. (Учитывает переключатель «Все»/«Улучшения»/«Яды».)»
4. **`ControlPanel.tsx`**, кнопка «Тройные сочетания» — прямо на кнопке:
   «Вывести сочетания трёх ингредиентов, дающих максимальное количество
   эффектов. (Учитывает переключатель «Все»/«Улучшения»/«Яды».)»

Явно не включено в этот заход (обсуждали и отклонили/отложили):
- Пояснение механики «Найти сочетания» (каждое выбранное свойство должно
  встречаться минимум у 2 ингредиентов) — отклонено: приложение рассчитано
  на игроков Skyrim, которые уже знают правила алхимии.
- Подсказки у «Ингредиент»/«Свойство N» в редакторе базы, у «Дополнения к
  игре» в Настройках — не запрошены, можно добавить отдельным заходом позже
  при необходимости.

## Компонент `HintIcon`

Новый файл `src/components/HintIcon.tsx` — единственная точка использования
`@tabler/icons-react` в проекте (зависимость уже есть в `package.json`, но
нигде не импортировалась).

```tsx
interface HintIconProps {
  label: string;
}

export function HintIcon({ label }: HintIconProps) {
  return (
    <Tooltip label={label} multiline w={260} withArrow>
      <ActionIcon
        variant="subtle"
        color="gray"
        size="xs"
        onClick={(e) => e.stopPropagation()}
        aria-label="Подсказка"
      >
        <IconHelpCircle size={14} />
      </ActionIcon>
    </Tooltip>
  );
}
```

Ключевые решения:
- **Иконка — `IconHelpCircle`** (знак вопроса в кружке), не `IconInfoCircle`
  — так пользователь сам описал элемент.
- **`onClick={(e) => e.stopPropagation()}`** — обязательно, когда `HintIcon`
  используется внутри кликабельной кнопки (`rightSection`, см. пункты 3-4):
  без этого клик по значку (не только наведение) запускал бы саму кнопку
  («Тройные сочетания» — не катастрофично благодаря уже существующему
  диалогу подтверждения, но всё равно лишнее и не то, чего ожидает
  пользователь). Наведение (hover) в любом случае безопасно — `onClick`
  кнопки не срабатывает от наведения.
- **Один компонент на оба сценария размещения** (отдельно у текстовой метки
  и встроенно в кнопку через `rightSection`) — `stopPropagation` безвреден
  в отдельностоящем варианте (там нет родительского `onClick`), значит
  не нужно два варианта компонента.
- `multiline w={260}` — тексты подсказок (особенно у «Парные»/«Тройные
  сочетания») длиннее одной строки, нужен перенос с разумной шириной.

## Точки интеграции

**`ControlPanel.tsx`** — кнопки уже растянуты на всю ширину сайдбара
(родительский `Stack` растягивает детей по умолчанию, `align="stretch"`) —
это и делает их сейчас одинаковой ширины, не длина текста. Добавление
`rightSection={<HintIcon label="..." />}` не меняет общую ширину кнопки —
значок просто занимает часть уже существующего свободного места у правого
края, размер кнопки визуально не меняется.

**`SettingsModal.tsx`** — `TextInput`'s проп `label` принимает `ReactNode`
(не только строку), значит можно передать `<Group gap={6}
align="center"><span>Макс. кол-во сочетаний</span><HintIcon label="..."
/></Group>` вместо строки — без изменения структуры компонента.

**`EditorModal.tsx`** — `HintIcon` добавляется третьим элементом в уже
существующий `<Group gap={6} align="baseline">` (сейчас там подпись
«Описание» и дополнительный текст «(Только для текущего языка)»).

## Тестирование

В проекте нет фронтенд-тестового раннера (см. прецедент B2b/B3+B4) —
верификация как обычно: `npx tsc -b` + `npm run build` + `npm run lint`.
Визуальная проверка — попросить пользователя запустить `npm run tauri dev`
самостоятельно (см. правило проекта про визуальную проверку).
