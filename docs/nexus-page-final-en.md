## Description (BBCode)

```bbcode
[center][size=5][b]Alchemist's Handbook for Skyrim[/b][/size][/center]

[center]A desktop companion tool for alchemy in [i]The Elder Scrolls V: Skyrim[/i].[/center]

[size=4][b]Description[/b][/size]

A fully standalone tool, independent of the game itself, that finds every possible combination of alchemy ingredients for a potion with the effects you want — and doubles as a reference for the properties of every ingredient in Skyrim, from the base game to the official add-ons (Dawnguard, Dragonborn, Hearthfire, and more). Settings let you control which sources are active, so you can exclude ingredients you don't actually have.

The interface is fully translated into 9 languages: English, Russian, German, Spanish, French, Italian, Polish, Japanese and Chinese. Translations use the wording from the game's official localizations.

The ingredient database is editable: you can change ingredient descriptions and images, and add new ingredients so they're included in the combination search.

[size=4][b]Features[/b][/size]

[list]
[*][b]Search by effects.[/b] Pick up to 4 desired effects and a filter (All / Buffs / Poisons) — get every matching 2- or 3-ingredient combination.
[*][b]Best pairs / best triples.[/b] One click to find the ingredient pairs or triples with the most matching effects — no manual effect selection needed.
[*][b]Ingredient browser.[/b] Pick any ingredient to see its full effect list, image and description.
[*][b]Editable database.[/b] Add, rename or delete ingredients; edit their 4 effects, image and description — add ingredients from new mods, or edit existing ingredient descriptions as you see fit.
[*][b]Toggleable sources.[/b] Turn the base game, each official add-on, Rare Curios, or your own custom ingredients on/off individually — search results respect only the enabled sources.
[*][b]9-language interface[/b], switchable in Settings without restarting.
[*][b]Interface options.[/b] UI scale (small/normal/large), color theme (light/dark/system/Skyrim-styled), and a cap on the number of combinations shown.
[*][b]Fully portable.[/b] No installer, no registry writes — the database and settings live next to the executable. Window layout (size, position, panel widths) is remembered between launches.
[/list]

[size=4][b]How to Use[/b][/size]

[b]1. Search combinations by effects[/b]
Pick up to 4 desired effects (yellow box) and a property-type filter — All / Buffs / Poisons (purple box), then click Find Combinations (red box). The matching ingredient list appears on the right (blue box), along with every 2- or 3-ingredient combination that gives those effects (green box). Each ingredient in that list has its own checkbox, letting you fine-tune the combination search — handy if you don't actually have a particular ingredient: just uncheck it, and the search will stop suggesting combinations that use it.

[img]PASTE_URL_2a[/img]

[b]2. Best pairs and triples in one click[/b]
The Pair Combinations and Triple Combinations buttons (red box) instantly find the pairs or triples with the most matching effects — no manual effect selection needed. Hover the (i) icon next to the button for a description.

[img]PASTE_URL_4a[/img]

[b]3. Ingredient info[/b]
Pick an ingredient from the list and click Show Properties — its 4 effects, image and description appear on the right.

[img]PASTE_URL_3[/img]

[b]4. Editing the database[/b]
File → Edit Database lets you add a new ingredient, or edit its effects, image and description — handy for recording your own finds or adjusting entries for mod-added ingredients.

[img]PASTE_URL_5[/img]

[b]5. Switching the interface language[/b]
Pick a language from the list in Settings — the interface switches instantly, no restart needed.

[img]PASTE_URL_1-1[/img]

[b]6. Toggling ingredient sources[/b]
Also in Settings: turn each ingredient source on or off individually (base game, official add-ons, Rare Curios, your own additions) — search results respect only the enabled sources.

[img]PASTE_URL_1[/img]

[size=4][b]Requirements[/b][/size]

Windows 10/11, with the [url=https://developer.microsoft.com/microsoft-edge/webview2/]WebView2 Runtime[/url] installed (already bundled with up-to-date Windows 10/11 — if missing, the app will prompt you to install it).

[size=4][b]Installation[/b][/size]

No installer needed — just download the archive, extract it anywhere, and run the .exe. The ingredient database is baked directly into the executable, so there's nothing else to copy alongside it.

[color=#e0a030][b]Note:[/b][/color] the .exe isn't code-signed, so Windows SmartScreen (or your antivirus) will likely warn about an "unrecognized publisher" on first run. This is normal for small independent tools without a paid signing certificate — click "More info" → "Run anyway".
```
